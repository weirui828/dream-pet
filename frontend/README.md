# Dream Pet web UI

Next.js 16 + Tailwind 4 client for the Dream Pet API.

```bash
npm install
cp .env.local.example .env.local   # NEXT_PUBLIC_API_URL, defaults to http://127.0.0.1:8000
npm run dev                         # http://localhost:3000
```

Paste the admin token (from the backend's `.secrets`) on the Settings screen.
